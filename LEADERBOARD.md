## Enter the board

Run the frozen suite against your agent, convert the run with `scripts/build_results.py`, and submit the results JSON plus a public link to your agent by pull request. Maintainers rerun every submitted agent against the frozen suite before a row is merged. Full guide: [BENCHMARK.md](BENCHMARK.md).
